# DotA Imba Legends: порт под Warcraft III 1.31

Карта **DotA Imba Legends v5.1f** (Ingame.ro / MyLifeBeLike), перенесённая на WC3 1.31.
Оригинал заброшен. Здесь ведём свои версии: hotfix by **glembelbi** (boga_imbi_net, LESBIS).

```
maps/   готовые карты, по одной на версию
src/    war3map.j и war3map.w3i текущей версии; правки делаются здесь
tools/  сборка, распаковка, проверка под 1.31 (Python 3, без зависимостей)
```

## Быстрый цикл правки

```bash
# 1. правишь src/war3map.j (и/или src/war3map.w3i)
python3 tools/check131.py src/war3map.j          # ловит то, что ломало 1.31
python3 tools/build.py maps/DotA_Imba_Legends_v5.1g.w3x maps/DotA_Imba_Legends_v5.1h.w3x
# 2. кладёшь карту в Документы\Warcraft III\Maps\Download и ПЕРЕЗАПУСКАЕШЬ игру
# 3. проверил -> добавил запись в Changelog ниже, коммит, тег v5.1h
```

`build.py` берёт предыдущую карту как контейнер (ландшафт, объекты, модели) и подменяет в ней файлы из `src/`.
Сборка детерминированная: из `src/` текущей версии получается побайтово та же карта, что лежит в `maps/`.

## Подводные камни

### 1. «Ошибка при чтении карты» в 1.31 = скрипт не компилируется
1.31 компилирует `war3map.j` ещё в меню выбора карты. Любая ошибка компиляции даёт эту надпись, а **какая строка виновата, игра не пишет**.

- **Подтверждённая причина.** `local` с тем же именем, что у параметра функции. 1.26 это прощал, 1.31 — нет.
  - В 5.1f таких функций было две: `GYV` (снаряды скиллов) и `R3O` (Kraken Shell).
  - Исправлено переименованием переменной в `IMBA131_<функция>_<имя>`. Поведение 1:1: в R3O баг «вешается на GetTriggerUnit, а не на параметр» сохранён.
  - `tools/check131.py` ловит это автоматически, `tools/patch_shadow.py` чинит.
- **Сделано превентивно, необходимость не доказана:**
  - 3 строки длиннее 1000 символов разбиты на функции `IMBA131_Cond1..3`;
  - 5 отладочных строк в Latin-1 переведены в UTF-8;
  - в `war3map.w3i` дописаны 12 нулевых байт: оригинальный w3i обрезан после таблицы апгрейдов.
- **Если снова не читается**, ищи виновника делением пополам (`tools/stub.py`):
  - опустошаешь тела половины функций (`return 0/false/null`), собираешь тестовые карты и смотришь, какая не открывается;
  - функции `config` и `InitCustomTeams` не трогай никогда;
  - так ошибка находится за 2–3 раунда.

### 2. Не открывать карту в World Editor и не пересохранять
Триггеров (`wtg/wct`) в карте нет, скрипт обфусцирован (`HPV`, `YKR`, `GYV`…). WE при сохранении перегенерирует `war3map.j` из пустых триггеров и **уничтожит карту**. Правим только `src/war3map.j` и собираем через `tools/build.py`.

### 3. Защита от Ingame.ro снята, но базой для сборок служит только наша карта
Оригинальный 5.1f защищён:
- зашифрованные файлы;
- неполный listfile: 128 имён на 1126 записей;
- мусорные блоки, указывающие за пределы архива;
- сектора по 4 МБ.

Карта 5.1g — уже чистая пересборка. Поэтому базой для `build.py` всегда служит **предыдущая версия из `maps/`**, а не оригинал. Сторонние MPQ-редакторы на оригинале могут молча потерять безымянные файлы.

### 4. Игра кэширует список карт и держит файл
- **Список карт.** Новый файл или новое описание не видны, пока Warcraft не перезапущен. Отсюда «почему опять 5.1f».
- **Блокировка файла.** Пока игра запущена, файл карты занят и не перезаписывается. Либо закрыть игру, либо класть под новым именем.

### 5. Где что лежит
| Что | Где |
|---|---|
| Название в лобби, описание, «Version …» | `src/war3map.w3i` (строки по `\0`, правится байтовой заменой; длину менять можно) |
| Имя в заголовке файла (`HM3W`) | первые 512 байт карты; в лобби не показывается |
| Стартовый текст «Hotfix by glembelbi» (20 с) | `src/war3map.j`, ищи `Hotfix|r by glembelbi` |
| Команда `-zoom` | функции `IMBA131_Zoom*` перед `main`, вызов `IMBA131_ZoomInit()` в конце `main` |
| Часть текстов (например, бывший «Rules:», совет про `-eb`) | не в скрипте: `GetObjectName('Amgl')`, `GetObjectName('Agra')` — имена объектов из object data |
| Удалённое | список «Banned combos» (функция `B4V`, её логика random seed оставлена), квест «Hotfix» в F9 |

Ключевые обфусцированные функции:
- `HPV(src, target, type, amount)` — нанести урон;
- `CZV(abilId, "func")` — регистрация обработчика скилла;
- `YKR` / `YKR2` — общий обработчик каста;
- `GYV` — самонаводящийся снаряд;
- `ZMR` — обработка урона;
- `VBI` — смерть юнита;
- `Y7/A7/E8/n7/X8/E7` — хэштаблица по `StringHash`.

### 6. Игроки и нейтралы
Карта старого формата (w3i v25), поэтому 1.31 запускает её в режиме 12 игроков. Нейтралы остаются на `Player(12..15)`. **Не переводить карту на 24 игрока** и не трогать эти номера: на них завязаны Рошан, Nightmare Prison и баунти.

### 7. Баги, которые оставлены намеренно
Версия «1:1 со всеми багами». Без отдельного решения не чинить:
- **Баг с триггером урона.** Флаг `HasRegisterDmgTrigger` в хэштаблице не очищается. Новый герой (`-recreate`, поздний пик) может унаследовать флаг, и на него перестают действовать пассивки при ударе.
- **Некр:** аура под вижином фармит всю карту и засыпает её предметами (крэши на долгих играх).
- **Рошан не респавнится,** если убит под Nightmare Prison: перед смертью его владелец меняется на Player 15.
- Утечки памяти (memory leaks) из оригинала.

### 8. Кодировка и строки JASS
- Скрипт хранится в UTF-8 с CRLF. Править в редакторе, который не меняет переводы строк (`.gitattributes` защищает от git).
- Цвет пишется как `|cAARRGGBB…|r`, перевод строки — `|n`.
- Строковый литерал не длиннее ~1000 символов: длинный текст склеивать через `+`.

## Клавиши как в iCCup (`hotkeys/IMBA_Keys.ahk`)
Маленькая программа на AutoHotkey v2, повторяет два блока из лаунчера iCCup: «Клавиши инвентаря» и «Клавиши способностей», у каждого своя галочка.
- Галочки и клавиши меняются на лету, прямо во время игры. Настройки хранятся в `IMBA_Keys.ini` рядом со скриптом.
- **Инвентарь** шлёт родные клавиши WC3 Numpad 7/8/4/5/1/2 и сам включает NumLock. По умолчанию: F2 F3 / ~ 1 / Tab Space.
- **Способности** кликают по ячейке панели команд, ряды 2 и 3. По умолчанию D F / Q W E R. Позиция панели берётся из размера окна, если клики промахиваются — кнопка «Калибровать» (F8 в игре).
- Работает только в окне Warcraft III (`Warcraft III.exe` / `war3.exe`). В чате (после Enter) клавиши не перехватываются. Ctrl/Alt-комбинации (Alt+Tab) не трогает.
- Почему не в карте: у JASS 1.31 нет native для смены hotkey.
